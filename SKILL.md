# Store Admin Kit

Use this skill when the user wants to manage stock, inventory levels, and order tracking.

## What to do
- confirm the stack and auth approach
- build a stock dashboard and order dashboard if needed
- let the admin update stock quantities and reorder levels
- show fulfillment statuses like pending, processing, shipped, and completed
- keep the back-office interface focused and readable

## Important
- do not build fake auth
- do not add extra admin sections unless requested
- keep forms simple and operational
- favor clarity, scanning speed, and real inventory workflows
