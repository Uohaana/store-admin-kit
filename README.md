# Store Admin Kit

A practical admin interface for managing inventory, orders, and store operations without turning the dashboard into a mess.

## Quick start

```bash
git clone https://github.com/Uohaana/store-admin-kit.git
cd store-admin-kit
```

Then open it in the browser or serve it locally:

```bash
python -m http.server 8000
```

Open:

```text
http://localhost:8000
```

## Features

- Inventory and stock management views
- Reorder alerts and operational status signals
- Order tracking and fulfillment workflow layout
- Simple admin flows built around real-world store needs
- Clear interface structure for non-technical operators

## Why this matters

Store operations are often more complicated than they look. The real challenge is not just showing data, but helping the right person understand what needs attention and what can wait.

This kit focuses on clarity: enough structure, enough context, and enough visual hierarchy to make operational decisions easier.

## Local run

### Requirements

- Modern browser
- Python 3.x or any simple static server

### Start it

```bash
python -m http.server 8000
```

## How it works

This interface is designed around the way store work actually flows: review, react, act. It highlights what matters most and keeps the rest in context, so the tool feels useful instead of overwhelming.

The goal is practical admin design: clean layout, obvious actions, and a workflow that supports real decisions.
